# Group 20 Capstone Planet Project

## Project Summary

This project is a React and Vite planetary data website built for the TSAcademy capstone. It presents a responsive space-themed page with a hero section, video section, fetched planet cards, a comparison table, and a contact form with client-side validation and user feedback after submission.

## How To Run The Project Locally

1. Clone the repository:

```bash
git clone https://github.com/Group20-capstone-project/capstone-planet-project.git
```

2. Move into the project folder:

```bash
cd capstone-planet-project/Ts-project
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local Vite URL shown in the terminal, usually:

```text
http://localhost:5173/
```

## Build Command

```bash
cd Ts-project
npm run build
```
